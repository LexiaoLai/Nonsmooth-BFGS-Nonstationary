def fraction(q):

def exact(q):
    if isinstance(q,float): raise TypeError('Use exact rational inputs.')
    return F(q)

_IV_GRID=2**256
def downward(q):
    q=exact(q)
    return F((q.numerator*_IV_GRID)//q.denominator,_IV_GRID)
def upward(q):
    return -downward(-exact(q))

class IV:
    def __init__(self,a,b=None):
        if isinstance(a,IV):
            if b is not None: raise TypeError('An interval copy has one argument.')
            self.lo,self.hi=a.lo,a.hi
        else:
            a,b=exact(a),exact(a if b is None else b)
            require(a<=b,'Unordered interval endpoints')
            self.lo,self.hi=downward(a),upward(b)
    def __add__(self,b):
        b=IV(b)
        return IV(self.lo+b.lo,self.hi+b.hi)
    __radd__=__add__
    def __neg__(self): return IV(-self.hi,-self.lo)
    def __sub__(self,b): return self+-IV(b)
    def __rsub__(self,b): return IV(b)+-self
    def __mul__(self,b):
        b=IV(b)
        products=[x*y for x in (self.lo,self.hi) for y in (b.lo,b.hi)]
        return IV(min(products),max(products))
    __rmul__=__mul__
    def __truediv__(self,b):
        b=IV(b)
        if b.lo<=0<=b.hi: raise ZeroDivisionError('Interval denominator contains zero.')
        return self*IV(1/b.hi,1/b.lo)
    def __rtruediv__(self,b): return IV(b)/self
    def mag(self): return max(abs(self.lo),abs(self.hi))

1. Data and isolated root

Manuscript: Section 2.1, Lemma 2.3, equations (2.3)–(2.9); the refined root interval is (A.3) in Appendix A.2.

The following exact definitions specify the quartic, involution, gradients, inverse Hessian matrices and positions. Endpoint signs and a derivative lower bound isolate the root in (0.9178,0.9179). Exact bisection on a decimal grid then computes a narrower interval Y, whose endpoint signs enclose the same root. The interpolation tables use the coarse interval; the remaining interval evaluations use Y. In the symbolic formulas, b is a free variable; polynomial remainders in Section 2 establish identities at the root. Interval evaluation replaces it by an independent variable λ∈Y, as in the appendix; a root identity is not assumed to hold for every λ.

The matrices H0,H1,J and constants ρ,r displayed below determine the cycle by

(g0,g1,g2,g3,g4)=(e1,e2,Je1,Je2,e1),(H2,H3,H4)=(ρJTH0J,ρJTH1J,rH0).

With v0=(b+3/2,b+1/2)T, the positions are

x0=(I+ρJT)v01−r,x1=x0−(1,1/2)T,(x2,x3,x4)=(ρJTx0,ρJTx1,rx0).

Finally, si=−Higi and yi=gi+1−gi for 0≤i<4, and fi=(gi)Txi for 0≤i≤4.

2. Exact cycle identities

Manuscript: Lemma 2.5, equations (2.11) and (2.12), in Section 2.1.

For a residual N(b)/D(b), a zero numerator remainder modulo P proves equality at its roots, provided gcd(D,P)=1. The original divisors are also checked before cancellation. The factorized update is B(H,s,y)=(I−syT/c)H(I−ysT/c)+ssT/c, where c=sTy. The tables report only the necessary divisor checks and the fourteen identities stated in the exact-cycle lemma.

def rational_parts(expression):
    require(not sp.sympify(expression).has(sp.Float),'Inexact symbolic input')
    numerator,denominator=sp.cancel(expression).as_numer_denom()
    return sp.Poly(numerator,b,domain=sp.QQ),sp.Poly(denominator,b,domain=sp.QQ)
def check_nonzero(expression):
    numerator,denominator=rational_parts(expression)
    gcds=[part.gcd(P).monic() for part in (numerator,denominator)]
    require(all(gcd.degree()==0 for gcd in gcds),'A divisor vanishes at a root')
    return [str(gcd.as_expr()) for gcd in gcds]
def check_equality(residual):
    matrix=residual if isinstance(residual,sp.MatrixBase) else sp.Matrix([residual])
    remainders=[]
    for entry in matrix:
        numerator,denominator=rational_parts(entry)
        require(denominator.gcd(P).degree()==0,'Undefined equality')
        remainder=numerator.rem(P)
        require(remainder.is_zero,'Nonzero polynomial remainder')
        remainders.append(remainder.as_expr())
    return sp.Matrix(matrix.rows,matrix.cols,remainders)

4. A concrete polynomial realization

Manuscript: an explicit realization of the interpolation conditions in Lemma 2.6 and the prescribed data in Lemma 2.10, Section 2.2.

The manuscript proves interpolation existence using Manni's parametric construction. The figures and Lean proof use the following independent polynomial construction satisfying the same conditions. These additional checks identify that concrete realization; its formula is not needed for the manuscript proof.

Adjoin identity data (t,t,1,0) at t=−1,6 and outer data of the same form at t=−2,7. On a gap [a,c] of length ℓ, use the rescaled endpoint data μ=ℓm, p=ℓda, q=ℓdc, P0=ℓ2ka, Q0=ℓ2kc and Δ=ηc−ηa. Choose the least n≥0 for which Ln=P0+(n+2)(p−μ)≥0, Rn=Q0−(n+2)(q−μ)≤0 and In=μ+2(p+q−2μ)/(n+4)+(P0−Q0)/((n+3)(n+4))<Δ. Such an integer exists because p,q,Δ>μ. Set

ψ(s)=μ+(1−s)n+2(p−μ+Lns)+sn+2(q−μ+Rn(s−1))+30(Δ−In)s2(1−s)2

and h(a+ℓs)=ηa+∫0sψ(u)du for 0≤s≤1. The added terms in ψ are nonnegative. Its endpoint values are p,q, its endpoint derivatives are P0,Q0, and its integral is Δ. Thus h matches the prescribed values and first two derivatives, with h′≥m. Joining the pieces and extending by the identity outside [−2,7] gives the required C2 semialgebraic functions.

The following cell certifies the least indices by rational intervals. Every smaller index is excluded by an interval proving failure of at least one condition. At n=0, cancel μ first to resolve the exact zero remaining integral on identity gaps.

5. Contraction toward the fixed ray

Manuscript: Proposition A.1 in Appendix A.2, used in Lemma 2.12 in Section 2.3.

Step 1: differentiate a BFGS step. In the state coordinates ω=(x1,x2,H11,H12,H22), a variation δω specifies δx and the symmetric matrix δH. At the cycle state ωi, equation (A.5) gives

δg=Kiδx,δs=−((δH)gi+Hiδg),δx^=δx+δs,δy=Ki+1δx^−δg.

With c=sTy, t=Hy, d=yTHy, N=tsT+stT and V=ssT, the update is H^=H−N/c+(c+d)V/c2. The product and quotient rules give δH^ in (A.7), implemented below. Evaluating at each standard basis vector δω gives the five columns of Di=DT(ωi), as in (A.8).

Step 2: form the derivative toward the fixed ray. Equations (A.9)–(A.10) give Dtot=D3D2D1D0=DT4(ω*) and

Aij=(Dtot)κiκj−(ω*)κi(Dtot)3κjr,(κ1,κ2,κ3,κ4)=(1,2,4,5).

Here ω*=(x10,x20,H110,H120,H220). Replacing b by λ∈Y defines the rational extension A^(λ), which satisfies A^(b)=A.

Step 3: certify the entry bounds and row sums. Use S from (A.4) and evaluate SA^(λ)S−1 by interval arithmetic. For each resulting interval Mij, compute mag(Mij) as the largest absolute endpoint and round it upward to three decimal places. These computed entries form Γ in (A.11). Summing its rows produces (A.12), which is then compared with the theorem's contraction threshold 0.78.

def diff_step(h,g,gp,k,kp,dx,dh):
    s=neg(mv(h,g));y=sub(gp,g);c=dot(s,y)
    dg=mv(k,dx);ds=neg(add(mv(dh,g),mv(h,dg)))
    dxp=add(dx,ds);dy=sub(mv(kp,dxp),dg)
    dc=dot(ds,y)+dot(s,dy)
    t=mv(h,y);d=dot(y,t);N=ma(outer(t,s),outer(s,t));V=outer(s,s)
    dt=add(mv(dh,y),mv(h,dy));dd=2*dot(dy,t)+dot(y,mv(dh,y))
    dV=ma(outer(ds,s),outer(s,ds))
    dN=ma(ma(outer(dt,s),outer(t,ds)),ma(outer(ds,t),outer(s,dt)))
    hp=ma(ma(dh,ms(dN,-1/c)),ms(N,dc/(c*c)))
    hp=ma(hp,ms(V,(dc+dd)/(c*c)-2*(c+d)*dc/(c*c*c)))
    hp=ma(hp,ms(dV,(c+d)/(c*c)))
    return pack(dxp,hp)
